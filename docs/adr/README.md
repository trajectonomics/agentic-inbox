# Architecture Decision Records (ADR)

This directory records architectural and technical decisions made in `trajectonomics/agentic-inbox`.

## Naming & Structure

Records are numbered consecutively: `NNNN-title.md` (e.g. `0001-use-durable-objects-for-mailboxes.md`).

Each record includes:
- **Title & Status**: (Draft, Accepted, Superseded)
- **Context**: Problem statement, constraints, alternatives evaluated.
- **Decision**: The selected architectural approach.
- **Consequences**: Positive, negative, and operational tradeoffs.
